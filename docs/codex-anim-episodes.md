# 給 Codex 的指令：補畫 12 個情境「完整版」的畫面

**使用方法**：把下面「指令」整段複製，貼給 Codex。畫很多，建議請 Codex **一次做 3～4 個情境**（例如先做 S01–S04），做完推上去，再請它做下一批。

---

## 指令

請在 GitHub 倉庫 `snoopyteacher888/sedu.learnspace` 的 **`animation-assets-original` 分支**，為社會技巧情境 S01–S04、S06–S13 各補畫 11 張關鍵畫面（第 35–45 格）。

**重要：所有工作都在 `animation-assets-original` 分支上做，不要推到 `main`，也不要開 PR 合併到 `main`。** 開始前先執行 `git checkout animation-assets-original`。

### 用途
網站要把每個情境做成約 3 分鐘的「完整版」影片，裡面有「倒帶：喬治的心裡話」「策略加油站（喬治示範，學生跟著做）」「換個地方也能用」「本週挑戰」四段，需要新的畫面。

### 共同規定（每一張都要遵守）
- 先打開該情境資料夾現有的 31 張，沿用**一模一樣的畫風、光線、場景和角色外型**。
- 角色只能用 `frame-list.json` 的 `cast` 裡的人：喬治、小晴、阿明、小如、大偉、導師、店員。**不要加入新角色。**
- 溫暖日系手繪動畫風格，16:9 橫式，約 1672 × 941。畫面不要有文字、對話框、漫畫符號或浮水印。表情自然、不誇張。
- **35–36（心裡話近景）**：喬治胸口以上的近景，背景是同一個場景、稍微模糊。
- **37–40（策略示範）**：喬治在原本的場景裡**面向觀眾示範**，人在畫面中間偏左，右邊留一些乾淨的背景（網站會在右邊放提示卡）。四張依序對應下表的四個步驟。
- **41–44（換個地方也能用）**：兩個新的小場景，各 2 張（41→42 是一組、43→44 是一組），前一張是「遇到狀況」，後一張是「用對的方法處理」。可以用學校裡的其他地方（教室、走廊、操場、圖書角、美勞桌），但要和現有畫風一致。
- **45（本週挑戰）**：喬治在原本的場景面向觀眾，微笑比出大拇指，表情有自信。

### 每個情境要畫什麼
檔名：`<資料夾名>_Frame_XX.png`，放在原本的資料夾（例如 `S01_hall/S01_hall_Frame_35.png`）。

### 放進倉庫
1. 確認在 `animation-assets-original` 分支，每個情境的 11 張放在原本的資料夾。
2. 在 `frame-list.json` 的 `frames` 加上這些畫面（`kind` 寫 `"episode"`，`action` 寫上面的描述）。
3. 每做完一批就 commit（例如「補畫完整版畫面 S01–S04」），推到 **`animation-assets-original` 分支**。
4. 推完告訴老師，老師再請 Claude 接進網站。

# 給 Codex 的指令：補畫情境 5「被笑的時候」完整版的畫面

**使用方法**：把下面「指令」整段複製，貼給 Codex。

---

## 指令

請在 GitHub 倉庫 `snoopyteacher888/sedu.learnspace` 的 **`animation-assets-original` 分支**，為社會技巧情境 5 補畫 11 張關鍵畫面。

**重要：所有工作都在 `animation-assets-original` 分支上做，不要推到 `main`，也不要開 PR 合併到 `main`。** 開始前先執行 `git checkout animation-assets-original`。

### 用途
網站把情境 5 做成約 3 分鐘的「完整版」影片，裡面有「倒帶：喬治的心裡話」「策略加油站（跟著一起做）」「換個地方也能用」三段。這三段目前重複用舊畫面，需要新的畫面。

### 畫風和角色：一定要和現有畫面完全一致
- 先打開 `social-skills/animation-assets/S05_laugh/` 現有的 31 張，沿用一模一樣的教室、光線、畫風和角色外型。
- 角色照 `frame-list.json` 的 `cast`：喬治（深棕短髮、暖橘色上衣、灰藍長褲）、阿明（黑色短髮、鼠尾草綠上衣）、小晴（棕色及肩髮、粉色上衣）、大偉、小如、導師。**不要加入新角色。**
- 溫暖日系手繪動畫風格，16:9 橫式，約 1672 × 941。畫面不要有文字、對話框、漫畫符號或浮水印。
- 第 32–37 張是「喬治示範給觀眾看」，喬治在畫面中間偏左，右邊留一些乾淨的背景（網站會在右邊放提示卡）。

### 畫面清單（檔名 `S05_laugh_Frame_XX.png`，放在 `social-skills/animation-assets/S05_laugh/`）

**倒帶：身體警報**
- **32** 喬治胸口以上的近景：臉頰泛紅、眉頭皺起、咬著嘴唇，一隻手握拳在胸前（感覺生氣的身體反應）。
- **33** 喬治近景：一隻手放在胸口，眼睛往下看，表情像在感覺「心跳好快」。

**策略加油站：跟著一起做（喬治面向觀眾示範）**
- **34** 喬治坐在自己的座位上，背挺直，雙手平放在大腿上，身體停住不動，表情認真。
- **35** 同樣坐姿：喬治閉眼、慢慢吸氣，胸口微微鼓起、肩膀稍微抬起。
- **36** 同樣坐姿：喬治吐氣，肩膀放鬆下來，表情變平靜、嘴角微微放鬆。
- **37** 喬治站在教室中間，面向觀眾，表情平穩，一隻手輕放在胸前，像在溫和地說「我不喜歡你這樣笑我」。

**換個地方也能用**
- **38** 美勞課（同一間教室，桌上有畫紙和水彩）：阿明看著喬治的畫，摀著嘴偷笑；喬治皺眉、握緊畫筆。
- **39** 同一個場景：喬治深呼吸後，平靜地看著阿明說話；阿明收起笑容，表情有點不好意思。
- **40** 下課的操場邊（參考 `S04_join` 的操場）：喬治和小晴玩猜拳或跳格子，喬治輸了，小晴笑出聲；喬治臉紅、握拳。
- **41** 同一個場景：喬治手放胸口深呼吸後，平靜地對小晴說話；小晴點點頭，表情抱歉。

**本週挑戰**
- **42** 教室裡，喬治面向觀眾，微笑比出大拇指，表情有自信、溫暖。

### 放進倉庫
1. 確認在 `animation-assets-original` 分支，11 張放到 `social-skills/animation-assets/S05_laugh/`。
2. 在 `frame-list.json` 的 `frames` 加上這 11 張（`scene` 寫 5，`scene_id` 寫 `"laugh"`，`kind` 寫 `"episode"`，`action` 寫上面的描述）。
3. commit 訊息寫「補畫情境 5 完整版的畫面」，推到 **`animation-assets-original` 分支**。
4. 推完告訴老師，老師再請 Claude 把畫面接進完整版影片。

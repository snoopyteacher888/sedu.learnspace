# 給 Codex 的指令：畫喬治的頭像

**使用方法**：把下面「指令」整段複製，貼給 Codex。

---

## 指令

請幫我畫一張兒童角色頭像，並放進 GitHub 倉庫 `snoopyteacher888/sedu.learnspace`。

**要畫什麼**
- 角色：喬治，一個大約 8 歲的台灣小男孩，是社會技巧教學網站的主角。
- 構圖：頭和肩膀的大頭像（胸像），臉朝正前方，在畫面正中間，四周留一點空白，不要切到頭髮。
- 表情：親切、自然的微笑，眼睛看著前方，讓小朋友覺得他是可以一起練習的好朋友。
- 外型：圓圓的臉、大眼睛（眼睛裡有白色亮點）、粉紅色臉頰；深咖啡色短髮，前面有幾撮翹翹的瀏海。
- 衣服：橘色上衣（顏色接近 #F08A3C），白色 V 字領口。
- 風格：兒童繪本、Q 版、扁平向量插圖，線條清楚、顏色柔和溫暖，適合國小學生。

**背景一定要透明**
- 輸出 **PNG**，**背景完全透明**（要有 alpha 透明通道）。不要白色背景、不要色塊、不要圓形底框、不要地上的影子。
- 如果沒辦法直接畫出透明背景：先畫在純綠色（#00FF00）背景上，再把綠色去背、輸出成透明 PNG。邊緣要乾淨，不能留下綠邊或白邊。
- 畫面裡不要有任何文字、浮水印或簽名。

**尺寸和檔名**
- 正方形，1024 × 1024 像素。
- 檔名：`george.png`（全部小寫）。

**放進網站**
1. 把 `george.png` 放到倉庫的 `social-skills/images/george.png`（網頁已經寫好會讀這個位置，不用改程式）。
2. 檢查透明背景：圖片四個角落的像素都要是完全透明（alpha = 0）。如果不是，請重新去背。
3. commit 訊息寫「新增喬治頭像（透明背景）」，推到 `main`。
